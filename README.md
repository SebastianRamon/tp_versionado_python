# Control de Gastos Personales

**Autor:** Sebastián Ramón  
**Materia:** Fundamentos de Ingeniería de Software II  
**Trabajo Práctico:** TP N.º 4 - Gestión de Versionado del Software

## Descripción

Este proyecto consiste en una aplicación de consola desarrollada en Python.

El sistema permite registrar y consultar gastos personales.

## Funcionalidades iniciales

- Registrar gastos.
- Listar gastos registrados.

## Requisitos

- Python 3
- Git

## Ejecución

Para ejecutar el programa:

```bash
python app.py
```
## Funcionalidades

La primera versión del sistema permite:

- Registrar gastos.
- Listar los gastos registrados.

El proyecto se encuentra en desarrollo y posteriormente se incorporarán
nuevas funcionalidades para mejorar la administración de los gastos.
